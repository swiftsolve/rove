# src

The React UI. Its two guides are imported here, so they load with any file
under `src/`, before the first line is written: how the UI is built (where
code goes, styles, tests, the library and which component to use), then the
design rules (which token for what, and why). A rule either one marks as
checked fails `npm run check`; the rest are yours to watch.
