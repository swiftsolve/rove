# Bundled lookup tables come from sources a binary may redistribute

Vendor names come from the IEEE's OUI registry, and country and ASN from
DB-IP's lite databases (CC BY 4.0), each regenerated by a `rove-core`
example. A table shipped inside an installed app can't be recalled, so a
source's licence has to allow that.

## Considered options

- **Wireshark's `manuf`** for vendors: GPL-2.0, which would bind the binary.
- **MaxMind GeoLite2** for geography: its EULA requires deleting superseded
  copies within 30 days of each release, which copies on users' machines
  can't honour.

## Consequences

- **Attribution ships with the app:** the README's Bundled data table and
  DB-IP's credit.
