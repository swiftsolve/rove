# Page refresh buttons say Refresh, except Devices

A page header's refresh button says Refresh, and Refreshing… while it runs,
on Connection, Timeline and Interfaces. Devices says Scan again and
Scanning…, because it runs a LAN scan: slower, louder on the network, and on
macOS behind the Local Network permission. Error retries keep Try again.
